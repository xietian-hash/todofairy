# 待办小程序 - 轻量马卡龙风格 UI 设计规范（v2）

## 一、设计核心原则

1. **轻量无压**：低饱和配色 + 充足留白，降低认知负担。
2. **单页高效**：以首页为主视图，日历与待办同屏完成核心操作。
3. **状态清晰**：优先表达“执行状态 + 失效标记 + 日历四态”，避免歧义。
4. **一致落地**：所有端遵循同一套颜色、间距、字体、动效和交互规则。

## 二、设计令牌（Design Tokens）

### 1）基础色令牌

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg-page` | `#E8F4F8` | 页面背景 |
| `--color-bg-card` | `#FFFFFF` | 卡片/弹窗背景 |
| `--color-text-primary` | `#1F2937` | 主文本 |
| `--color-text-secondary` | `#64748B` | 次级文本 |
| `--color-border` | `#DCE7EE` | 分割线/描边 |
| `--color-brand` | `#4299E1` | 主要交互色 |
| `--color-brand-press` | `#3182CE` | 主要交互按下态 |

### 2）业务状态色令牌

#### A. 待办执行态（`status`）

| 状态 | 规则 | 色值建议 |
|---|---|---|
| 未完成 | `status=1` | 卡片底 `#FFFFFF`，文本 `#1F2937` |
| 已完成 | `status=2` | 卡片底 `#F0FDF4`，文本 `#64748B`，勾选 `#10B981` |

#### B. 待办失效标记（`isExpired`）

| 状态 | 规则 | 色值建议 |
|---|---|---|
| 已失效 | `status=1 && isExpired=true` | 标签底 `#FEE2E2`，标签字 `#B91C1C` |
| 未失效 | `isExpired=false` | 不展示失效标签 |

#### C. 日历四态

| 日历状态 | 判定 | 色值建议 |
|---|---|---|
| 已完成 | `completedCount=todoCount && todoCount>0` | `#DCFCE7` |
| 历史未完成 | `targetDate<today && uncompletedCount>0` | `#FEE2E2` |
| 当日未完成 | `targetDate=today && uncompletedCount>0` | `#FEF3C7` |
| 无待办 | `todoCount=0` | `#E2E8F0` |

### 3）尺寸令牌

| Token | 值（rpx） | 用途 |
|---|---:|---|
| `--space-page-x` | 30 | 页面左右边距 |
| `--space-page-y` | 20 | 页面上下边距 |
| `--space-section` | 30 | 模块间距 |
| `--radius-card` | 16 | 卡片圆角 |
| `--radius-modal` | 24 | 弹窗圆角 |
| `--size-touch-min` | 88 | 最小可点击区域 |

## 三、布局规范

### 1）首页布局（唯一主页面）

- 上半区：月历（含状态色与选中日期）
- 下半区：待办进度 + 待办列表
- 底部：固定“+ 新建任务”按钮
- 说明：历史待办通过切换日历日期查看，不提供独立历史页面

### 2）任务弹窗布局（非独立路由页）

| 区块 | 规则 |
|---|---|
| 弹窗宽度 | `690rpx`（左右各留白约 `30rpx`） |
| 弹窗圆角 | `24rpx` |
| 头部区 | 高 `96rpx`，左标题右关闭 |
| 内容区 | 表单纵向排列，项间距 `20rpx` |
| 底部按钮区 | 两按钮等宽，最小高度 `88rpx` |
| 遮罩层 | `rgba(15,23,42,0.45)`，点击遮罩可关闭（可配开关） |

## 四、组件规范

### 1）待办卡片

| 项 | 规范 |
|---|---|
| 基础 | 白底、圆角 `16rpx`、描边 `1rpx #DCE7EE`、内边距 `24rpx` |
| 已完成态 | 底色 `#F0FDF4`，标题可加删除线，辅助文案 `#64748B` |
| 已失效标记 | 固定在待办文本区域最右侧展示“已失效”标签（红底浅色） |
| 点击反馈 | 仅背景轻微变亮，不加阴影跳变 |
| 布局 | 文本区域在左，勾选按钮固定在整行最右侧 |

### 2）勾选框

| 状态 | 规范 |
|---|---|
| 未选中 | 圆形，直径 `40rpx`，描边 `2rpx #CBD5E1` |
| 选中 | 圆形，直径 `40rpx`，填充 `#10B981` + 白色对勾 |
| 位置 | 固定在待办行最右侧，避免遮挡标题与标签 |
| 点击区 | 外围点击热区不小于 `88rpx x 88rpx` |
| 交互 | 支持双向切换：未完成->已完成；已完成->未完成 |

### 3）按钮

| 类型 | 样式 |
|---|---|
| 主按钮（新建/保存） | 蓝底白字，圆角 `60rpx` |
| 次按钮（取消/删除） | 白底蓝字 + 蓝色描边 |
| 禁用态 | `#CBD5E1` 文本 + `#F1F5F9` 背景 |

### 4）表单输入（任务弹窗）

- 输入框高度 `80rpx`，圆角 `12rpx`，边框 `1rpx #DCE7EE`
- 聚焦态边框：`#4299E1`
- 错误态边框：`#EF4444`，并显示错误提示文案

## 五、文字规范

| 文字类型 | 字号（rpx） | 字重 | 颜色 |
|---|---:|---:|---|
| 页面标题 | 36 | 600 | `#1F2937` |
| 卡片主文案 | 32 | 400 | `#1F2937` |
| 辅助文案 | 24 | 400 | `#64748B` |
| 按钮文案 | 28 | 500 | 跟随按钮 |

补充规则：
- 行高建议 `1.6`，避免信息过密。
- 超长文本最多 2 行，超出显示省略号。
- 小字号文本避免使用低于 `#64748B` 的对比度。

## 六、动效规范

### 核心动效（最多 3 种）

| 场景 | 规则 |
|---|---|
| 新增待办 | 轻淡入（`opacity: 0 -> 1`，`0.2s`） |
| 完成待办 | 勾选框微缩放（`0.95 -> 1`，`0.2s`） |
| 删除待办 | 水平滑出 + 淡出（`0.25s`） |

动效约束：
- 禁止闪烁、旋转、大幅位移。
- 单次动效时长不超过 `0.3s`。
- 加载阶段优先静态骨架，不使用高频闪烁动画。

## 七、页面状态规范

| 页面状态 | 触发条件 | 展示规范 |
|---|---|---|
| 加载中 | 首次进入/下拉刷新 | 显示静态骨架占位（卡片块 + 日历占位） |
| 空态 | 选中日期无待办 | 显示空态插图 + 文案 + “新建任务”按钮 |
| 错误态 | 接口失败/网络异常 | 显示错误提示与“重试”按钮 |
| 内容态 | 数据正常返回 | 展示日历与待办列表 |

## 八、适配与可访问性

- 全部尺寸统一使用 `rpx`，禁止与 `px` 混用。
- 关键点击目标最小 `88rpx x 88rpx`。
- 文字与背景对比度建议不低于 `4.5:1`。
- 横屏时卡片区域居中，最大内容宽度建议 `750rpx`。

## 十、落地检查清单

1. 日历四态与 PRD 口径一致（已完成/历史未完成/当日未完成/无待办）。
2. 待办仅两种执行态（未完成/已完成），失效通过 `isExpired` 单独呈现。
3. 首页 + 任务弹窗交互闭环，无新增独立历史页面。
4. 全量尺寸单位为 `rpx`，触控热区达标。
5. 设计稿、前端样式、PRD 状态字段三方一致。
