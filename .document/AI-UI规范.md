# 待办小程序 - 轻拟物质感 UI 设计规范（v3 薄荷青春）

## 一、设计核心原则

1. **轻拟物质感（Soft Neumorphism）**：核心交互区域采用"嵌入式"或"浮雕式"视觉表现，通过细微的光影关系塑造物理触感，拒绝纯扁平与重度拟物。
2. **青春活力**：以薄荷绿为主色调，搭配明快的状态色，营造清新、朝气、愉悦的视觉体验。
3. **单页高效**：以首页为主视图，日历与待办同屏完成核心操作。
4. **状态清晰**：优先表达"执行状态 + 失效标记 + 日历四态"，避免歧义。
5. **一致落地**：所有端遵循同一套颜色、阴影、间距、字体、动效和交互规则。

## 二、设计令牌（Design Tokens）

### 1）基础色令牌

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg-page` | `#C9F0E4` | 页面背景（薄荷绿，拟物阴影基准面） |
| `--color-bg-card` | `#E0F7EF` | 卡片/弹窗背景（浅薄荷，浮雕高光面） |
| `--color-text-primary` | `#1A3C34` | 主文本（深墨绿） |
| `--color-text-secondary` | `#5B8A7A` | 次级文本（灰绿） |
| `--color-border` | `#A8DCC8` | 分割线/描边（柔和绿） |
| `--color-brand` | `#00C9A7` | 主要交互色（活力青绿） |
| `--color-brand-press` | `#00B396` | 主要交互按下态 |
| `--color-brand-light` | `#E6FFF8` | 品牌浅底（用于选中态背景等） |

### 2）拟物阴影令牌

拟物效果的核心在于同一元素同时具有亮侧（左上高光）和暗侧（右下投影）两层阴影，模拟柔和光源。

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-convex` | `6rpx 6rpx 12rpx rgba(0,0,0,0.08), -6rpx -6rpx 12rpx rgba(255,255,255,0.9)` | 外凸浮雕（卡片、按钮默认态） |
| `--shadow-concave` | `inset 4rpx 4rpx 8rpx rgba(0,0,0,0.1), inset -4rpx -4rpx 8rpx rgba(255,255,255,0.7)` | 内凹嵌入（按下态、输入框、未选中勾选框） |
| `--shadow-flat` | `none` | 无阴影（禁用态） |

使用规则：
- 拟物阴影仅作用于 `--color-bg-page` 或 `--color-bg-card` 等纯色背景上，禁止在渐变/图片背景上叠加拟物阴影。
- 阴影色始终基于背景色的明暗偏移生成，不使用纯黑投影。
- 嵌套层级最多 2 层（如页面 > 卡片 > 勾选框），避免光影关系混乱。

### 3）业务状态色令牌

#### A. 待办执行态（`status`）

| 状态 | 规则 | 色值建议 |
|---|---|---|
| 未完成 | `status=1` | 卡片底 `--color-bg-card`（`#E0F7EF`），文本 `--color-text-primary` |
| 已完成 | `status=2` | 卡片底 `#D1F5E8`，文本 `--color-text-secondary`，勾选填充 `#10B981` |

#### B. 待办失效标记（`isExpired`）

| 状态 | 规则 | 色值建议 |
|---|---|---|
| 已失效 | `status=1 && isExpired=true` | 标签底 `#FEE2E2`，标签字 `#B91C1C` |
| 未失效 | `isExpired=false` | 不展示失效标签 |

#### C. 日历四态

| 日历状态 | 判定 | 色值 |
|---|---|---|
| 已完成 | `completedCount=todoCount && todoCount>0` | `#A7F3D0`（翠绿） |
| 历史未完成 | `targetDate<today && uncompletedCount>0` | `#FECACA`（珊瑚粉） |
| 当日未完成 | `targetDate=today && uncompletedCount>0` | `#FDE68A`（活力黄） |
| 无待办 | `todoCount=0` | `#D1E5DB`（灰薄荷） |

### 4）尺寸令牌

| Token | 值（rpx） | 用途 |
|---|---:|---|
| `--space-page-x` | 30 | 页面左右边距 |
| `--space-page-y` | 20 | 页面上下边距 |
| `--space-section` | 30 | 模块间距 |
| `--radius-card` | 20 | 卡片圆角（拟物风格适当加大） |
| `--radius-modal` | 28 | 弹窗圆角 |
| `--radius-btn` | 60 | 按钮圆角（胶囊形） |
| `--radius-input` | 16 | 输入框圆角 |
| `--size-touch-min` | 88 | 最小可点击区域 |

## 三、布局规范

### 1）首页布局（唯一主页面）

- 上半区：月历（含四态色与选中日期拟物凹陷效果）
- 下半区：待办进度 + 待办列表（卡片浮雕排列）
- 底部：固定"+ 新建任务"浮雕按钮
- 说明：历史待办通过切换日历日期查看，不提供独立历史页面

### 2）任务弹窗布局（非独立路由页）

| 区块 | 规则 |
|---|---|
| 弹窗宽度 | `100%`（贴满屏幕宽度） |
| 弹窗高度 | `80vh`（约屏幕五分之四） |
| 弹窗圆角 | `28rpx`（仅顶部左右圆角） |
| 弹窗背景 | `--color-bg-card`（`#E0F7EF`） |
| 头部区 | 高 `96rpx`，左标题右关闭；关闭按钮为 `72rpx` 圆形浮雕，`X` 居中 |
| 内容区 | 表单纵向排列，项间距 `20rpx`，左右内边距 `30rpx`，内部滚动且隐藏系统滚动条 |
| 底部按钮区 | 两按钮等宽，高 `88rpx`，文案需上下居中，按钮区固定在弹窗底部 |
| 遮罩层 | 半透明遮罩 `rgba(0,0,0,0.3)`，点击弹窗外空白区域关闭 |

## 四、组件规范

### 1）待办卡片

| 项 | 规范 |
|---|---|
| 基础 | 背景 `--color-bg-card`，圆角 `20rpx`，无描边，内边距 `24rpx`，应用 `--shadow-convex` 浮雕阴影 |
| 已完成态 | 底色 `#D1F5E8`，标题加删除线（`text-decoration: line-through`），辅助文案 `--color-text-secondary` |
| 已失效标记 | 固定在待办文本区域右侧展示"已失效"标签（底 `#FEE2E2`，字 `#B91C1C`，圆角 `8rpx`） |
| 点击反馈 | 按下时阴影从 `--shadow-convex` 过渡到 `--shadow-concave`，模拟物理按压感 |
| 布局 | 文本区域在左，勾选按钮固定在整行最右侧 |
| 卡片间距 | 卡片之间间距 `16rpx` |

### 2）勾选框

| 状态 | 规范 |
|---|---|
| 未选中 | 圆形，直径 `44rpx`，背景 `--color-bg-card`，应用 `--shadow-concave` 内凹效果，无描边 |
| 选中 | 圆形，直径 `44rpx`，填充 `#10B981`，应用 `--shadow-convex` 外凸效果，内部白色对勾 |
| 位置 | 固定在待办行最右侧，避免遮挡标题与标签 |
| 点击区 | 外围点击热区不小于 `88rpx x 88rpx` |
| 交互 | 支持双向切换：未完成->已完成；已完成->未完成 |
| 过渡 | 选中/取消选中时阴影切换动画 `0.2s ease` |

### 3）按钮

| 类型 | 样式 |
|---|---|
| 主按钮（新建/保存） | 背景 `--color-brand`（`#00C9A7`），白色文字，圆角 `--radius-btn`，应用 `--shadow-convex` |
| 主按钮按下态 | 背景 `--color-brand-press`（`#00B396`），阴影切换为 `--shadow-concave` |
| 次按钮（取消） | 背景 `--color-bg-card`，文字 `--color-brand`，无描边，应用 `--shadow-convex` |
| 次按钮按下态 | 阴影切换为 `--shadow-concave` |
| 文案对齐 | 按钮文案必须水平垂直居中 |
| 禁用态 | 文本 `#93C5B4`，背景 `#D1E5DB`，阴影 `--shadow-flat` |

### 4）表单输入（任务弹窗）

| 项 | 规范 |
|---|---|
| 基础 | 高度 `80rpx`，圆角 `--radius-input`（`16rpx`），背景 `--color-bg-card`，应用 `--shadow-concave`（嵌入凹陷），无描边 |
| 聚焦态 | 凹陷阴影加深：`inset 4rpx 4rpx 10rpx rgba(0,0,0,0.12), inset -4rpx -4rpx 10rpx rgba(255,255,255,0.6)`，底部出现 `2rpx` 品牌色指示线 |
| 错误态 | 底部指示线改为 `#EF4444`，并在输入框下方显示错误提示文案（字色 `#B91C1C`，字号 `22rpx`） |
| placeholder | 文字色 `#93C5B4` |
| 结束日期 | 可为空；为空时表示长期有效 |

### 5）日历格子

| 状态 | 规范 |
|---|---|
| 默认 | 背景 `--color-bg-card`，圆角 `12rpx`，应用轻度 `--shadow-convex` |
| 选中 | 背景 `--color-brand-light`（`#E6FFF8`），阴影切换为 `--shadow-concave`（凹陷表示按下选中），文字加粗 |
| 今日标记 | 日期数字下方显示 `6rpx` 圆点，颜色 `--color-brand` |
| 四态底色 | 叠加在格子背景上，四态色值见设计令牌章节 |
| 非本月日期 | 文字色 `#93C5B4`，不展示状态色，不响应点击 |

## 五、文字规范

| 文字类型 | 字号（rpx） | 字重 | 颜色 |
|---|---:|---:|---|
| 页面标题 | 36 | 600 | `--color-text-primary`（`#1A3C34`） |
| 月份标题 | 32 | 600 | `--color-text-primary` |
| 日历日期 | 28 | 400 | `--color-text-primary` |
| 卡片主文案 | 32 | 400 | `--color-text-primary` |
| 辅助文案 | 24 | 400 | `--color-text-secondary`（`#5B8A7A`） |
| 按钮文案 | 28 | 500 | 跟随按钮规范 |
| 失效标签 | 22 | 400 | `#B91C1C` |

补充规则：
- 行高建议 `1.6`，避免信息过密。
- 超长文本最多 2 行，超出显示省略号。
- 文字与背景对比度不低于 `4.5:1`。

## 六、动效规范

### 核心动效

| 场景 | 规则 |
|---|---|
| 新增待办 | 轻淡入（`opacity: 0 -> 1`，`0.2s ease`） |
| 完成待办 | 勾选框微缩放（`0.95 -> 1`，`0.2s ease`） |
| 任务弹窗开关 | 自底部快速滑入/滑出（`translateY(100%) -> 0`，`0.2s ease`） |
| 按下反馈（拟物） | 阴影从 `--shadow-convex` 过渡到 `--shadow-concave`（`0.15s ease`） |
| 日历格子选中 | 阴影过渡 `0.15s ease` |

动效约束：
- 禁止闪烁、旋转、大幅位移。
- 单次动效时长不超过 `0.3s`。
- 加载阶段优先静态骨架，不使用高频闪烁动画。
- 拟物阴影过渡使用 `transition: box-shadow`，禁止用 JS 逐帧模拟。

## 七、页面状态规范

| 页面状态 | 触发条件 | 展示规范 |
|---|---|---|
| 加载中 | 首次进入/下拉刷新 | 显示拟物风格骨架占位（浮雕色块 + 日历占位） |
| 空态 | 选中日期无待办 | 显示空态插图 + 文案 + "新建任务"浮雕按钮 |
| 错误态 | 接口失败/网络异常 | 显示错误提示与"重试"浮雕按钮 |
| 内容态 | 数据正常返回 | 展示日历与待办列表 |

## 八、适配与可访问性

- 全部尺寸统一使用 `rpx`，禁止与 `px` 混用。
- 关键点击目标最小 `88rpx x 88rpx`。
- 文字与背景对比度不低于 `4.5:1`。
- 横屏时卡片区域居中，最大内容宽度建议 `750rpx`。
- 拟物阴影在低端机型上应提供降级方案：当检测到渲染性能不足时，回退为 `1rpx` 描边 + 纯色背景。

## 九、暗黑模式（可选）

暗黑模式下拟物效果通过调暗背景 + 加深暗侧阴影 + 提亮亮侧阴影实现。

### 1）基础映射

| 白天 | 暗黑 | 用途 |
|---|---|---|
| `#C9F0E4` | `#0D1F1A` | 页面背景 |
| `#E0F7EF` | `#162B24` | 卡片/弹窗背景 |
| `#1A3C34` | `#E0F7EF` | 主文本 |
| `#5B8A7A` | `#7EBDAA` | 次级文本 |
| `#A8DCC8` | `#2A4A3E` | 边框/分割线 |
| `#00C9A7` | `#00E4BE` | 品牌色（暗黑下适当提亮） |

### 2）拟物阴影映射

| 白天 | 暗黑 |
|---|---|
| `--shadow-convex`：亮侧 `rgba(255,255,255,0.9)` | 亮侧 `rgba(255,255,255,0.05)` |
| `--shadow-convex`：暗侧 `rgba(0,0,0,0.08)` | 暗侧 `rgba(0,0,0,0.4)` |
| `--shadow-concave`：亮侧 `rgba(255,255,255,0.7)` | 亮侧 `rgba(255,255,255,0.03)` |
| `--shadow-concave`：暗侧 `rgba(0,0,0,0.1)` | 暗侧 `rgba(0,0,0,0.5)` |

### 3）日历四态映射

### 4）失效标记映射

| 标记 | 白天 | 暗黑 |

## 十、落地检查清单

1. 日历四态与 PRD 口径一致（已完成/历史未完成/当日未完成/无待办）。
2. 待办仅两种执行态（未完成/已完成），失效通过 `isExpired` 单独呈现。
3. 首页 + 任务弹窗交互闭环，无新增独立历史页面。
4. 全量尺寸单位为 `rpx`，触控热区达标。
5. 所有卡片、按钮、输入框、勾选框均应用拟物阴影令牌，禁止硬编码阴影值。
6. 按下态统一从 `--shadow-convex` 过渡到 `--shadow-concave`，过渡时间 `0.15s`。
7. 暗黑模式下拟物阴影正确映射，光影关系不反转。
8. 低端机型降级方案已实现（回退为描边 + 纯色）。
9. 设计稿、前端样式、PRD 状态字段三方一致。
