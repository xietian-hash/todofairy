# 待办小程序 - 轻拟物质感 UI 设计规范（v7 渐变拟物）

## 一、设计核心原则

1. **轻拟物质感（Soft Neumorphism）**：核心交互区域采用"嵌入式"或"浮雕式"视觉表现，通过细微的光影关系塑造物理触感，拒绝纯扁平与重度拟物。
2. **明快通透 + 渐变点缀**：白色底板搭配活力蓝（`#21BFFF`）品牌色，关键交互元素引入蓝紫渐变（`#21BFFF → #6C5CE7`），提升品质感与视觉层次。
3. **单页高效**：以首页为主视图，日历与待办同屏完成核心操作。
4. **状态清晰**：优先表达"执行状态 + 失效标记 + 日历四态"，避免歧义。
5. **一致落地**：所有端遵循同一套颜色、阴影、间距、字体、动效和交互规则。

## 二、设计令牌（Design Tokens）

### 1）基础色令牌

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg-page` | `#F5F7FA` | 页面背景（极浅灰白，为白色卡片提供层次） |
| `--color-bg-card` | `#FFFFFF` | 卡片/弹窗背景（纯白） |
| `--color-text-primary` | `#1E293B` | 主文本（深石墨） |
| `--color-text-secondary` | `#64748B` | 次级文本（中灰） |
| `--color-border` | `#E2E8F0` | 分割线/描边 |
| `--color-brand` | `#21BFFF` | 主要交互色（活力蓝） |
| `--color-brand-press` | `#0EA5E9` | 主要交互按下态 |
| `--color-brand-light` | `#E0F5FF` | 品牌浅底（用于选中态背景等） |
| `--color-accent` | `#6C5CE7` | 渐变终点色（星空紫） |
| `--gradient-brand` | `linear-gradient(135deg, #21BFFF, #6C5CE7)` | 品牌渐变（主按钮、勾选框、进度条） |
| `--gradient-brand-press` | `linear-gradient(135deg, #0EA5E9, #5B4BD5)` | 品牌渐变按下态 |

### 2）拟物阴影令牌

白色背景下拟物阴影暗侧对比更清晰，亮侧为纯白，光影关系最自然。

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-convex` | `6rpx 6rpx 14rpx rgba(0,0,0,0.07), -6rpx -6rpx 14rpx rgba(255,255,255,1)` | 外凸浮雕（卡片、按钮默认态） |
| `--shadow-concave` | `inset 4rpx 4rpx 8rpx rgba(0,0,0,0.08), inset -4rpx -4rpx 8rpx rgba(255,255,255,1)` | 内凹嵌入（按下态、输入框、未选中勾选框） |
| `--shadow-flat` | `none` | 无阴影（禁用态） |

使用规则：
- 拟物阴影仅作用于 `--color-bg-page` 或 `--color-bg-card` 等纯色背景上，禁止在渐变/图片背景上叠加拟物阴影。
- 阴影色始终基于背景色的明暗偏移生成，不使用纯黑投影。
- 嵌套层级最多 2 层（如页面 > 卡片 > 勾选框），避免光影关系混乱。

### 3）业务状态色令牌

#### A. 待办执行态（`status`）

| 状态 | 规则 | 色值建议 |
|---|---|---|
| 未完成 | `status=1` | 卡片底 `--color-bg-card`（`#FFFFFF`），文本 `--color-text-primary` |
| 已完成 | `status=2` | 卡片底 `#F0FDFA`，文本 `--color-text-secondary`，勾选填充 `--gradient-brand`（蓝紫渐变） |

#### B. 待办失效标记（`isExpired`）

| 状态 | 规则 | 色值建议 |
|---|---|---|
| 已失效 | `status=1 && isExpired=true` | 标签底 `#FEE2E2`，标签字 `#B91C1C` |
| 未失效 | `isExpired=false` | 不展示失效标签 |

#### C. 日历四态

| 日历状态 | 判定 | 色值 |
|---|---|---|
| 已完成 | `completedCount=todoCount && todoCount>0` | `#BAE6FD`（天蓝） |
| 历史未完成 | `targetDate<today && uncompletedCount>0` | `#FECACA`（珊瑚粉） |
| 当日未完成 | `targetDate=today && uncompletedCount>0` | `#F1F5F9`（浅灰，与无待办一致，仅靠今日圆点区分） |
| 无待办 | `todoCount=0` | `#F1F5F9`（浅灰） |

> 选中态规则：选中已完成（`#BAE6FD`）或历史未完成（`#FECACA`）日期时，保留原状态背景色 + 品牌蓝边框 + 凹陷阴影；其他状态选中时使用渐变背景。

## 三、布局规范

### 1）首页布局（唯一主页面）

- 上半区：月历卡片（顶部渐变横幅 + 四态色 + 选中日期拟物凹陷效果）
- 下半区：待办视图显示“进度条 + 待办列表”；任务视图显示任务列表卡片
- 底部：固定左/中/右三段交互（菜单占位、待办/任务切换、右侧“+”新建）
- 说明：历史待办通过切换日历日期查看，不提供独立历史页面

### 2）任务弹窗布局（非独立路由页）

| 区块 | 规则 |
|---|---|
| 弹窗宽度 | `100%`（贴满屏幕宽度） |
| 弹窗高度 | `80vh`（约屏幕五分之四） |
| 弹窗圆角 | `28rpx`（仅顶部左右圆角） |
| 弹窗背景 | `--color-bg-card`（`#FFFFFF`） |
| 头部区 | 高 `96rpx`，左标题右关闭；关闭按钮为 `72rpx` 圆形浮雕，`X` 居中 |
| 内容区 | 表单纵向排列，项间距 `20rpx`，左右内边距 `30rpx`，内部滚动且隐藏系统滚动条 |
| 底部按钮区 | 两按钮等宽，高 `88rpx`，文案需上下居中，按钮区固定在弹窗底部 |
| 遮罩层 | 半透明遮罩 `rgba(0,0,0,0.3)`，点击弹窗外空白区域关闭 |

## 四、组件规范

### 1）待办卡片

| 项 | 规范 |
|---|---|
| 基础 | 背景 `--color-bg-card`，圆角 `20rpx`，无描边，内边距 `24rpx`，应用 `--shadow-convex` 浮雕阴影，左侧 `4rpx` 品牌色（`#21BFFF`）竖条装饰 |
| 标签信息 | 若存在标签，在标题旁展示轻量标签胶囊（建议浅蓝底 `#E0F5FF`、文字 `#0369A1`） |
| 已完成态 | 底色 `#F0FDFA`，标题文字色 `--color-text-secondary`（不加删除线），左侧色条改为 `#10B981`（翠绿） |
| 已失效标记 | 固定在待办文本区域右侧展示"已失效"标签（底 `#FEE2E2`，字 `#B91C1C`，圆角 `8rpx`），左侧色条改为 `#94A3B8`（灰色） |
| 点击反馈 | 按下时阴影从 `--shadow-convex` 过渡到 `--shadow-concave`，模拟物理按压感 |
| 布局 | 文本区域在左，勾选按钮固定在整行最右侧 |
| 卡片间距 | 卡片之间间距 `16rpx` |

### 2）勾选框

| 状态 | 规范 |
|---|---|
| 未选中 | 圆形，直径 `44rpx`，背景 `--color-bg-card`，应用 `--shadow-concave` 内凹效果，无描边 |
| 选中 | 圆形，直径 `44rpx`，填充 `--gradient-brand`（蓝紫渐变），应用 `--shadow-convex` 外凸效果，内部白色对勾 |
| 位置 | 固定在待办行最右侧，避免遮挡标题与标签 |
| 点击区 | 外围点击热区不小于 `88rpx x 88rpx` |
| 交互 | 支持双向切换：未完成->已完成；已完成->未完成 |
| 过渡 | 选中/取消选中时阴影切换动画 `0.2s ease` |

### 3）待办左滑删除

| 项 | 规范 |
|---|---|
| 手势方向 | 待办项仅响应水平左滑；纵向滑动优先页面滚动 |
| 操作区宽度 | 删除操作区宽度 `156rpx`，默认隐藏在卡片右侧 |
| 触发阈值 | 左滑超过操作区宽度 `40%` 时吸附展开，否则回弹关闭 |
| 互斥规则 | 同一时刻仅允许一个待办项展开删除操作区 |
| 删除按钮 | 红色渐变（建议 `#EF4444 -> #DC2626`），白色文字“删除”，圆角跟随卡片 `20rpx` |
| 误触保护 | 删除按钮仅在展开后可点击；展开态点击待办卡片区域先收起不触发勾选 |

### 3.1）任务左滑操作（编辑 + 删除）

| 项 | 规范 |
|---|---|
| 手势方向 | 任务项仅响应水平左滑；纵向滑动优先页面滚动 |
| 操作区宽度 | 操作区总宽度 `312rpx`（编辑 `156rpx` + 删除 `156rpx`），默认隐藏在卡片右侧 |
| 触发阈值 | 左滑超过操作区宽度 `40%` 时吸附展开，否则回弹关闭 |
| 互斥规则 | 同一时刻仅允许一个任务项展开操作区 |
| 按钮布局 | 从左到右依次为“编辑”“删除”；编辑按钮位于删除按钮左侧 |
| 编辑按钮 | 蓝色渐变（建议 `#0EA5E9 -> #0284C7`），白色文字“编辑”，圆角跟随卡片 `20rpx` |
| 删除按钮 | 红色渐变（建议 `#EF4444 -> #DC2626`），白色文字“删除”，圆角跟随卡片 `20rpx` |
| 误触保护 | 展开态点击任务卡片区域先收起操作区，不触发其他动作 |
| 卡片点击 | 未展开时点击任务卡片直接打开编辑弹窗；展开态点击仅收起操作区，不直接进入编辑 |

### 4）按钮

| 类型 | 样式 |
|---|---|
| 主按钮（新建/保存） | 背景 `--gradient-brand`（蓝紫渐变），白色文字，圆角 `--radius-btn`，应用 `--shadow-convex` |
| 主按钮按下态 | 背景 `--gradient-brand-press`，阴影切换为 `--shadow-concave` |
| 次按钮（取消） | 背景 `--color-bg-card`，文字 `--color-brand`，无描边，应用 `--shadow-convex` |
| 次按钮按下态 | 阴影切换为 `--shadow-concave` |
| 文案对齐 | 按钮文案必须水平垂直居中 |
| 禁用态 | 文本 `#94A3B8`，背景 `#F1F5F9`，阴影 `--shadow-flat` |

### 5）表单输入（任务弹窗）

| 项 | 规范 |
|---|---|
| 基础 | 高度 `80rpx`，圆角 `--radius-input`（`16rpx`），背景 `--color-bg-card`，应用 `--shadow-concave`（嵌入凹陷），无描边，字号 `32rpx` |
| 标签 | 任务标题和备注说明不显示 label；标签选择器与日期选择器保留 label（字号 `24rpx`，色 `#64748B`） |
| 聚焦态 | 凹陷阴影加深：`inset 4rpx 4rpx 10rpx rgba(0,0,0,0.1), inset -4rpx -4rpx 10rpx rgba(255,255,255,1)`，底部出现 `2rpx` 品牌色指示线 |
| 错误态 | 底部指示线改为 `#EF4444`，并在输入框下方显示错误提示文案（字色 `#B91C1C`，字号 `22rpx`） |
| placeholder | 文字色 `#94A3B8`（统一适用于 input/textarea 原生 placeholder 及 picker 空值提示文案） |
| 结束日期 | 可为空；为空时显示"长期有效"，文字色 `#94A3B8` |
| 标签选择器 | 仅允许单选已有标签；无可选标签时展示"暂无可选标签"并禁用选择 |
| 自动聚焦 | 打开新建弹窗时标题输入框自动获得焦点（`focus=true`），弹出键盘 |
| 键盘适配 | 弹窗内 input/textarea 设置 `adjust-position=false`，防止键盘弹出时推动弹窗 |

### 7）日历格子

### 8）进度条

| 项 | 规范 |
|---|---|
| 轨道 | 高度 `16rpx`，圆角 `8rpx`，背景 `--color-bg-card`，应用 `--shadow-concave` 内凹效果 |
| 填充条 | 高度 `16rpx`，圆角 `8rpx`，背景 `--gradient-brand`（蓝紫渐变），宽度按完成百分比动态设置 |
| 标题行 | 左侧日期文字（`26rpx`，`--color-text-primary`），右侧已完成数/总数（`24rpx`，`--color-brand`） |

### 9）顶部Toast（全局组件）

| 项 | 规范 |
|---|---|
| 位置 | 固定在页面上方，需避让状态栏与自定义导航栏，建议 `top = statusBarHeight + navBarHeight + 12px` |
| 容器 | 左右边距 `30rpx`，最小高度 `72rpx`，矩形圆角 `8rpx`，白底 + 细描边（`#E2E8F0`） |
| 成功态 | 左侧 `8rpx` 色条为绿色（建议 `#22C55E`），文案深色 |
| 失败态 | 左侧 `8rpx` 色条为红色（建议 `#EF4444`），文案深色 |
| 信息态 | 左侧 `8rpx` 色条为品牌蓝（`#21BFFF`），文案深色 |
| 动效 | 进入/退出使用轻位移+淡入淡出（`0.2s ease`） |
| 防抖 | 同类型同文案提示在短时间窗口内（建议 `700ms`）只允许触发一次，防止重复激活 |
| 复用 | 以全局组件方式封装，页面通过统一调用入口触发，避免各页面样式分叉 |

### 10）任务列表卡片（任务视图）

| 项 | 规范 |
|---|---|
| 容器 | 与待办卡片保持统一圆角与浮雕阴影（`20rpx` + `--shadow-convex`） |
| 信息结构 | 第一行：任务标题；第二行：标签（可选）+ 生效日期区间 |
| 状态展示 | 任务列表不展示“启用/停用”状态胶囊，避免信息噪音 |
| 点击行为 | 点击任务卡片直接进入编辑；若卡片处于左滑展开态则优先收起操作区 |
| 字段省略 | 标题与日期区间超长时单行省略，避免卡片高度抖动 |

### 11）底部三段交互栏

| 项 | 规范 |
|---|---|
| 布局 | 左侧菜单占位按钮 + 中间切换控件 + 右侧新建按钮，固定吸底显示 |
| 尺寸 | 左/右按钮触控区不低于 `88rpx`，中间切换控件高度 `88rpx` |
| 切换方式 | 中间控件支持点击与局部左右滑动切换；切换阈值建议 `28px` |
| 视觉反馈 | 当前视图由滑块高亮；文字激活态为白色，未激活态为次级文字色 |
| 手势边界 | 仅中间切换控件响应左右滑动，避免与待办/任务项左滑操作冲突 |

## 五、文字规范

| 文字类型 | 字号（rpx） | 字重 | 颜色 |
|---|---:|---:|---|
| 页面标题 | 36 | 600 | `--color-text-primary`（`#1E293B`） |
| 月份标题 | 32 | 600 | `#FFFFFF`（渐变横幅内白色） |
| 日历日期 | 28 | 400 | `--color-text-primary` |
| 卡片主文案 | 32 | 400 | `--color-text-primary` |
| 辅助文案 | 24 | 400 | `--color-text-secondary`（`#64748B`） |
| 按钮文案 | 28 | 500 | 跟随按钮规范 |
| 失效标签 | 22 | 400 | `#B91C1C` |

补充规则：
- 行高建议 `1.6`，避免信息过密。
- 超长文本最多 2 行，超出显示省略号。
- 文字与背景对比度不低于 `4.5:1`。

## 六、动效规范

### 核心动效

| 场景 | 规则 |
|---|---|
| 新增待办 | 轻淡入（`opacity: 0 -> 1`，`0.2s ease`） |
| 完成待办 | 勾选框微缩放（`0.95 -> 1`，`0.2s ease`） |
| 左滑展开删除/操作 | 待办卡片 `translateX(0 -> -156rpx)`；任务卡片 `translateX(0 -> -312rpx)`，均使用 `0.2s ease`，拖动过程中禁用过渡 |
| 底部视图切换 | 切换滑块 `translateX` 过渡 `0.2s ease`，避免整页横向位移 |
| 顶部Toast | `opacity: 0 -> 1` + `translateY(-12rpx -> 0)`，`0.2s ease` |
| 任务弹窗开关 | 自底部快速滑入/滑出（`translateY(100%) -> 0`，`0.2s ease`） |
| 按下反馈（拟物） | 阴影从 `--shadow-convex` 过渡到 `--shadow-concave`（`0.15s ease`） |
| 日历格子选中 | 阴影过渡 `0.15s ease` |

动效约束：
- 禁止闪烁、旋转、大幅位移。
- 单次动效时长不超过 `0.3s`。
- 加载阶段优先静态骨架，不使用高频闪烁动画。
- 拟物阴影过渡使用 `transition: box-shadow`，禁止用 JS 逐帧模拟。

## 七、页面状态规范

| 页面状态 | 触发条件 | 展示规范 |
|---|---|---|
| 加载中 | 首次进入/下拉刷新 | 首页先渲染当月基础日历网格；待办视图会静默触发“当日补偿生成”后再回填四态颜色与列表数据；必要时显示拟物风格骨架占位 |
| 空态 | 当前视图无数据 | 显示空态文案，并引导使用底部右侧“+”创建任务 |
| 错误态 | 接口失败/网络异常 | 显示错误提示与"重试"浮雕按钮 |
| 内容态 | 数据正常返回 | 展示日历与待办/任务内容；当日补偿接口失败仅记录日志，不展示打扰性提示 |

## 八、适配与可访问性

- 全部尺寸统一使用 `rpx`，禁止与 `px` 混用。
- 关键点击目标最小 `88rpx x 88rpx`。
- 文字与背景对比度不低于 `4.5:1`。
- 横屏时卡片区域居中，最大内容宽度建议 `750rpx`。
- 拟物阴影在低端机型上应提供降级方案：当检测到渲染性能不足时，回退为 `1rpx` 描边 + 纯色背景。
